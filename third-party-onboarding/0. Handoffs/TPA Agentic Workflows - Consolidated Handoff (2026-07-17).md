## What this project is

A 5-agent LLM system (persona instructions written as `.md` "system prompt" files) that automates Keppel's Third-Party Agent (TPA) onboarding, renewal, KYC screening, and portfolio audit workflow, integrating with Dow Jones RCTP. The agents: `Doc Analyst` (raw document parsing, out of scope for this project — no `.md` file, opaque), `TPA DocReviewer` (schema extraction + delta comparison), `KYC/Screening Agent` a.k.a. `Screener` (UBO unravelling + sanctions screening), `Custodian` (portfolio-wide renewal sweep), `TPA Orchestrator` (routes everything, is the sole MCP/RCTP caller, produces the final consolidated report).

Governing spec: `1. UI UX/Onboarding Host Client - Product Requirements Document.md` (not modified this session — read it for the product's design principles, especially "review-not-create" and "evidence, not verdicts," both referenced repeatedly in the persona files).
